# 与 ProCCD 的功能对照

> 本表只做**功能层面**的对照，用于说明自研 App 覆盖了什么、缺什么。
> 项目未对 ProCCD 做反编译、资源提取或代码复用；两者不存在代码/素材关系。

| 能力 | ProCCD（参考） | 拾光 CCD v0.1 | 说明 |
|---|---|---|---|
| 实时滤镜预览 | ✅ | ✅ | CameraX `SurfaceProcessor` + 自研 GL 管线 |
| 多机型预设 | 多款（A620/BIGSHOT/2014&2000S/MG330…） | 6 款自研预设 | 名称与参数均为自研，不使用厂商型号 |
| 参数细调 | ISO/白平衡/曝光/饱和/噪点/暗角/光晕/色散/快门 | 曝光/色温/色调/饱和/中间调/颗粒/暗角/色散/柔光/清晰度 | 我们暂未暴露「快门速度」 |
| 时间戳 | ✅ | ✅ | 橙色 LED / 白色数码两种样式 |
| 边框 | ✅ | ✅（撕拉白边） | 仅一种 |
| 闪光灯 | ✅ | ✅（关/开/自动） | 依赖设备闪光灯 |
| 前后摄切换 | ✅ | ✅ | |
| 导入照片修图 | ✅ | ✅（可长按看原图） | |
| 保存到系统相册 | ✅ | ✅（API 29+） | API 26–28 存应用私有目录 |
| 原图保留 / 无损重编辑 | 部分支持 | ✅ | 应用内 sidecar 原图，可反复换预设 |
| 录像 / DV 滤镜 | ✅ | ❌ | 规划 v2 |
| 拼图 / 贴纸 / 模板 | ✅ | ❌ | 规划 v2 |
| Live Photo | iOS 专属 | ❌ | Android 无对应形态 |
| 美颜 | ✅ | ❌ | 非本项目重点 |
| 广告 / 联网 | 有广告、收集标识符 | 无网络权限、无广告、无统计 | 设计取舍 |
| 订阅 | 周/月/年/买断多档 | 无内购 | 本项目为自用/研究性质 |
